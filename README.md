# Mallamma Gutte Portfolio

A modern, professional React portfolio for Mallamma Gutte, a B.Tech Artificial Intelligence & Data Science student at REVA University, Bengaluru.

## Technologies

- React.js
- Vite
- JavaScript
- CSS
- React Icons

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Update Your Information

- Profile photo: replace the image at `public/profile.jpg` or use a new local image path in the relevant section.
- GitHub link: update the `socialLinks` object in `src/components/Contact.jsx` and `src/components/Footer.jsx`.
- LinkedIn link: update the `socialLinks` object in the same component files.
- Instagram link: update the `socialLinks` object in the same component files.
- Project links: update the button URLs in `src/components/Projects.jsx`.
- Certificate links: update the `certificateLinks` object in `src/components/Certifications.jsx`.
- Contact information: update the email, phone number, and address in `src/components/Contact.jsx`.

## Notes

The project uses placeholder links where real portfolio/profile URLs should eventually be added. This keeps the site functional and easy to customize for internship applications, networking, and professional branding.
